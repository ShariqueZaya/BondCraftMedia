# Bond Craft Media Website

A responsive, single-page digital marketing agency website built with
HTML, CSS and JavaScript.

## 1. Project files

- `index.html` — website content and homepage sections.
- `styles.css` — colours, layout, typography and responsive design.
- `script.js` — navigation, portfolio filters, WhatsApp links,
  video previews and enquiry form.
- `assets/logo.png` — agency logo.

## 2. Run the website in VS Code

1. Open VS Code.
2. Select File → Open Folder.
3. Open the folder containing your website files.
4. Install the Live Server extension if needed.
5. Right-click `index.html`.
6. Select Open with Live Server.
7. Your website should open in your browser.

Save your changes and refresh the browser to see them.

## 3. Change the logo

1. Open the `assets` folder.
2. Replace `logo.png` with your original high-quality logo.
3. Keep the filename as `logo.png`.

Alternatively, change `assets/logo.png` in the HTML wherever
the logo is used.

Use a square image for the cleanest result.

## 4. Change the website colours

Open `styles.css` and find the variables near the top:

```css
:root {
  --cream: #F7EFE5;
  --burgundy: #722632;
  --wine: #401923;
  --gold: #C8A96B;
}
